# 距離センサー4種ベンチマーク【短距離ユース版: 屋外・30〜40mレンジ】

親版（[`../README.md`](../README.md)・汎用/150m基準）の95機種台帳を母集団に、**屋外で30〜40m先を測距する用途**に絞って再構成したもの。
手法: ①長距離グレード除外（カタログ最大>120m or 車載長距離 or 生産終了）→ ②**LiDARは3D方式のみに限定**（1D単点・2D走査を除外し近〜中距離3D機を追補）→ ③判定閾値を30–40m要件基準に再設計 → ④分布集計（n/最小/中央値/最大）で〇△×判定。

## 結論（1行サマリ）

| | 超音波 | ステレオ | ミリ波 | LiDAR(3Dのみ) |
|---|---|---|---|---|
| 測距距離 | × (5m・不達) | × (実用~4.5m) | 〇 (中央値50m) | 〇 (中央値90m・17/20機≥40m) |
| 距離分解能@30–40m | × (域内測距不可) | × (1–3.4m@35m) | 〇 (3.75cm) | 〇 (±1–3cm) |
| 角度分解能 | × | 〇 (0.05°=3cm@35m) | ×〜△ (15°=9.2m@35m) | 〇 (0.18°=11cm@35m) |
| 雨・霧 | △ | × | 〇 | △ |
| 太陽光下 | 〇 | △ | 〇 | △(機種選定で回避可) |
| 暗闇 | 〇 | ×(補助光届かず) | 〇 | 〇 |
| サイズ(体積) | 〇 (57cm³) | 〇〜△ (185cm³) | 〇 (42.5cm³) | △ (461cm³) |
| コスト | 〇 (~$240) | △ (~$434) | 〇 (~$70) | × (~$3,500) |

**選定指針**: 存在・距離・速度だけなら**ミリ波**（最安¥1万・全天候・方位は捨てる）。方位・形状・分離が要るなら**3D LiDAR**——コスパ最適はLivox Mid-40/70/Horizon（¥9〜15万）、360°・実績重視ならOuster/VLP-16/XT32（¥60万〜）。定石は両者の併用。ステレオは昼間の認識補助のみ、超音波は選外。3D限定でLiDARはコスト×・サイズ△が確定（安価/小型な1D/2Dを含めていた前版の甘さを是正）。
