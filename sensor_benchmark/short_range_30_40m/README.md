# 距離センサー4種ベンチマーク【短距離ユース版: 屋外・30〜40mレンジ】

親版（[`../README.md`](../README.md)・汎用/150m基準）の95機種台帳を母集団に、**屋外で30〜40m先を測距する用途**に絞って再構成したもの。
手法: ①長距離グレード除外（カタログ最大>120m or 車載長距離 or 生産終了）→ ②同グレード帯で16機種補充 → ③判定閾値を30–40m要件基準に再設計 → ④分布集計（n/最小/中央値/最大）で〇△×判定。

**選定指針**: 存在・距離・速度だけなら**ミリ波**（最安・全天候・方位は捨てる）。方位・形状・分離が要るなら**LiDAR中距離グレード**（¥10〜60万・濃霧と直射日光のマージン設計が条件)。定石は両者の併用。ステレオは昼間の認識補助のみ、超音波は選外。
