# サイズ（体積）・コスト詳細（短距離ユース版: 屋外30〜40m）

母集団: フィルタ＋補充後85機種（[`01_raw_data_quantitative.csv`](01_raw_data_quantitative.csv)）。
体積は台帳寸法から算出（直方体=W×D×H、円筒=π(D/2)²H、チップ厚1mm仮定）。円換算1USD=150円目安。

### 直感的な大きさの目安

- **<1cm³** = 米粒〜角砂糖未満: レーダチップ全機種（0.03–0.2cm³）、超音波素子（0.5cm³）
- **10–70cm³** = 消しゴム〜マッチ箱数個: 1D LiDAR全機種（TF-Luna 10、LIDAR-Lite 38、TF02-Pro 66）、RFbeam K-MD2レーダ（3.8）
- **80–250cm³** = スマホ〜缶コーヒー: 車載コーナーレーダ（84–189）、2D LiDAR主流（175–208）、ステレオ主流（D435=56、ZED 2i=230）、**Livox Mid-360（254）**
- **440–650cm³** = 500mlペットボトル級: 40m級3D LiDARの主流（OS0/OS1=440、Mid-40=461、Horizon=576、VLP-16=600、XT32=642）
- **>1,000cm³** = 牛乳パック超: 屋外産業用2D（LMS111=1,735）、長基線ステレオ（rc_visard=1,449）

### 用途上の含意

1. **ミリ波が短距離セグメントでは体積最強**（中央値42.5cm³）。親版の中央値240cm³から劇的に小さくなったのは、長距離用の大型モジュール・機械走査型（3,400cm³）を除外した結果。チップ実装なら製品基板に消える。
2. **LiDARも親版558→197cm³に改善**。ただし**「3Dで40m」を満たす機種に絞ると中央値451cm³**（119–642cm³）で500mlペットボトル級が現実ライン。最小はUnitree L1（119cm³だが30m境界）、実質はMid-360（254cm³・265g）が小型側の代表。
3. **1D LiDARは体積10–66cm³で40m到達**（TF02-Pro・LIDAR-Lite v3）。「一点の距離だけ」で良いなら圧倒的に小さい。
4. ステレオの185cm³は数字上小さいが、前述のとおり基線制約で「幅」が縮まない（かつ本用途では測距×）。

## 3. 注意点

- 車載コーナーレーダの$70–80は**量産OEM推定**（数万個単位の調達前提）。単品開発では入手不可か10倍以上。
- Livox価格帯は発売時定価ベース。Mid-360は流通$480–550の実績もあり下振れ方向（親版注記参照）。
- 体積は外形寸法のみ。マウント・ケーブル・（ステレオは演算器、LiDARは電源ボックス）を含むシステム体積は1.5–3倍を見込むこと。
- `~`付き寸法・価格（補充機の一部）は参考・推定値。
