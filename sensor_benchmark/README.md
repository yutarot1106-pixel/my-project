# 距離センサー4種ベンチマーク（分布ベース定量エビデンス）

超音波ソナー／ステレオカメラ／ミリ波レーダ／LiDAR を8項目（測距距離・距離分解能・角度分解能・雨霧・太陽光・暗闇・サイズ・コスト）で比較。
カタログ値の単点引用ではなく、**機種単位の実数値を台帳化 → セルごとに n/最小/中央値/最大 を算出 → 中央値（分解能のみ最良絶対値）で〇△×判定**する方式。

## 成果物

| ファイル | 内容 |
|---|---|
| [`01_raw_data_quantitative.csv`](01_raw_data_quantitative.csv) | 生データ台帳（定量）: 95機種 × 測距距離/分解能/角度/サイズ/価格。機種名・数値・測定条件・用途グレード・出典URL付き |
| [`02_qualitative_evidence.csv`](02_qualitative_evidence.csv) | 生データ台帳（定性）: 雨霧15件・太陽光10件・暗闇10件の一次情報。定量代理指標（dB/km, klux, lux等）併記 |
| [`03_distribution_summary.md`](03_distribution_summary.md) | 分布サマリ表: セルごとの n/最小/中央値/最大/判定 |
| [`04_final_benchmark.md`](04_final_benchmark.md) | **最終ベンチマーク**: 8項目×4センサーの〇△×（中央値＋代表数値入り）＋既知確定事項との整合チェック |
| [`05_notes.md`](05_notes.md) | 注記: カタログvs実測の乖離・条件依存・出典間矛盾・サンプリング充足状況 |
