# 距離センサー4種ベンチマーク（分布ベース定量エビデンス）

超音波ソナー／ステレオカメラ／ミリ波レーダ／LiDAR を8項目（測距距離・距離分解能・角度分解能・雨霧・太陽光・暗闇・サイズ・コスト）で比較。
カタログ値の単点引用ではなく、**機種単位の実数値を台帳化 → セルごとに n/最小/中央値/最大 を算出 → 中央値（分解能のみ最良絶対値）で〇△×判定**する方式。
**LiDARは3D方式のみを対象**（1D単点・2D走査は本比較の趣旨=面的な形状/方位取得に適さないため除外、短〜長距離3D機を補充しn=23）。
